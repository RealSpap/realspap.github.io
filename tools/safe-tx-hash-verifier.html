Verify a Safe Transaction Hash

Fetches a proposed Safe transaction from the public Safe Transaction Service and computes its EIP-712 domain hash, message hash, and final Safe transaction hash independently, in your browser, using the ethers.js library. Compare the result below against what your hardware wallet displays before you approve anything.

What this tool does, and does not, tell you

It does not tell you a transaction is safe to sign. It only recomputes the hash from the same raw parameters the Safe front end used to build the signing request, so you have an independent value to compare against your hardware wallet's screen.

  • Your hardware wallet computes its own hash from whatever the connected app sends it. If that app is compromised, the wallet screen and this tool can both be shown correct-looking data that does not match the transaction actually being proposed: always re-check the to, value, and data fields below too, not only the final hash.
  • Compare the domain hash and message hash individually if your device shows them separately, then the final Safe transaction hash. If any single hex character differs anywhere, stop and do not sign.
  • It follows the approach of the open-source safe-tx-hashes-util by pcaversaccio: the same hashes, and the same warnings for an untrusted DelegateCall, a custom gas token or refund receiver, and a change to the Safe's owners or threshold (also inside a multiSend batch). A hash match with a warning still means the transaction can do exactly what the warning says.

Verify this tool's own math (offline, no network)

Runs the exact same hashing code against a published, independently-checkable example: no data leaves your browser and no API is called. Run this first if you want to trust the numbers below.

Get both from a source you trust independently (the chain's own docs, or Safe's published API list). A wrong chain ID here silently changes the domain hash with no error shown.

The nonce shown in the Safe app / your wallet for the transaction you're about to sign.

Runs entirely in your browser. On submit it calls the public Safe Transaction Service API (api.safe.global, or the API you enter for a custom chain) directly from your browser to read the raw transaction parameters. Nothing you enter is sent to any other server. Hashing uses ethers.js v6.13.4 loaded from cdnjs, pinned to an exact version and checked with Subresource Integrity: the browser refuses to run the file if its SHA-384 hash differs from the one written in this page. A Content Security Policy blocks any other script.

Reference implementation and methodology: pcaversaccio/safe-tx-hashes-util.
