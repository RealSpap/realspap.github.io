Check your Safe

Does one of your Safe’s signers also sign for another protocol?

This tool compares a Safe’s owners with 3 signer addresses that public research documents (two of them on two protocols each). Press Check on the example in the box, or paste your own Safe: in seconds you see whether one of the 3 is among its owners. No wallet, no account, nothing to pay.

The box holds a real example: Resolv’s own Ethereum Safe, listed in the research README as 4-of-6. Press Check to read it live from a public node, then type your own Safe.

Nothing is sent until you press a button. Then the address you type is sent only to a public Ethereum node (ethereum-rpc.publicnode.com, or, only if it fails, eth.drpc.org, then 1rpc.io); the one that answered is named under the result. Part 2 further down sends its own inputs to api.safe.global.

      Redo it yourself

      Ask any Ethereum node for the current owners and threshold. They rarely change, so it should match unless an owner was swapped since. For the exact block above you need an archive node (add --block and the number): public nodes often refuse old blocks.

      The 3 documented signer addresses come from the multisig-overlap-showcase research project, whose public README was last changed on 14 October 2026 (repository head cd823c1). The README gives two of them in full; the third, 0x8f02…d002, only shortened, and its full form is the one the former version of this tool already carried. The read of this Safe goes to the public node named under the result.

      Before you sign
      

      Check the hash of a transaction before you sign it
      

      Fetches a proposed Safe transaction from the public Safe Transaction Service and computes its EIP-712 domain hash, message hash, and final Safe transaction hash independently, in your browser, using the ethers.js library. Compare the result below against what your hardware wallet displays before you approve anything.
      

      
      
      What this tool does, and does not, tell you
      
      
      It does not tell you a transaction is safe to sign. It only recomputes
      the hash from the same raw parameters the Safe front end used to build the signing request, so you
      have an independent value to compare against your hardware wallet's screen.
      
      
        
        
      • Your hardware wallet computes its own hash from whatever the connected app sends it. If that
        app is compromised, the wallet screen and this tool can both be shown correct-looking data that
        does not match the transaction actually being proposed: always re-check the to,
        value, and data fields below too, not only the final hash.
        • 
        
      • Compare the domain hash and message hash individually if your
        device shows them separately, then the final Safe transaction hash. If any single
        hex character differs anywhere, stop and do not sign.
        • 
        
      • It follows the approach of the open-source safe-tx-hashes-util by pcaversaccio: the same hashes,
        and the same warnings for an untrusted DelegateCall, a custom gas token or refund receiver, and a
        change to the Safe's owners or threshold (also inside a multiSend batch). A hash match with a
        warning still means the transaction can do exactly what the warning says.
        •

      Proof
      
  
      
    
      Method
      getOwners() and getThreshold() are read on Ethereum mainnet at one block, and the block is shown in the result. Each owner is then compared, address for address, with the signer addresses documented in the research README. Nothing else is inferred.
      
    
      Dates
      Each reading shows its block and the time of that block, taken from the chain. The documented list was checked on 30 October 2026 against the README as last changed on 14 October 2026 (repository head cd823c1).
      
    
      Limits
      This page can match only the 3 signer addresses it contains. In its README of 14 October 2026, the research counts 8 addresses with signer power on two or more protocols on Ethereum mainnet, in a dataset of 411 protocol entries on 25 chains and 749 multisig addresses: this page does not search that dataset. The Safe is read on Ethereum mainnet only.
      
    
      Where your input goes
      Part 1: the Safe address you check goes to ethereum-rpc.publicnode.com and, only if that node fails, to eth.drpc.org, then 1rpc.io. Part 2: the Safe address, the nonce and the chain go to the Safe Transaction Service (api.safe.global, or, only when you type a custom chain API, that address). Nothing else is sent anywhere, there is no account and no tracker, and this page stores nothing in your browser. Opening the page loads ethers.js v6.13.4 from cdnjs for Part 2, checked with Subresource Integrity.
      
    
      Source
      Part 1 data: the multisig-overlap-showcase research project (public README; one of the 3 addresses appears there shortened, see above). Part 2 follows the approach of pcaversaccio/safe-tx-hashes-util. Built by RealSpap.
