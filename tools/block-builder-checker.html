Who built this block?

Enter an Ethereum block number, or leave it blank for the latest block. This reads that block's own miner field, live, straight from a public RPC endpoint, in your browser, and checks it against a short list of well-known builder addresses. Nothing is sent to any server other than the RPC endpoints below.

This is a short, hand-labeled list of publicly known builder identities, not an exhaustive registry. A block whose miner address isn't in this list is not necessarily suspicious, it likely just means a smaller builder, or a validator that built its own block instead of buying one.

This free check only answers one question, who built a given block, by reading that block's own fee-recipient field. The full research covers four layers of Ethereum's block market: who builds blocks (this one), who relays them, who actually gets paid, and who captures private order flow. The last three need relay-operator API access and on-chain payment tracing this static page doesn't attempt, so this tool says nothing about relays, payments, or order flow. Live charts and the full write-up: dune.com/s_pap/block-market-concentration. Questions or access to the full method: x.com/RealSpap.
