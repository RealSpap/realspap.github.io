contact@realspap.com · GitHub · X · Contact · Find my errors · Method and limits

There are no third-party scripts. You can run every command again yourself. The address reader on the home page sends nothing unless you click “Read this contract now”: that click asks a public Ethereum node about the address you typed and about the contracts behind it. The Oracle (testnet) dashboard contacts other hosts when you open it: GitHub, public blockchain nodes and an icon service. Findings, data, published code and blockchain sources are public. You can reuse them for free if you name RealSpap as the author. Licence, repository by repository: CC BY 4.0 for the data and the text of the three showcase repositories. MIT for their code, for onchain-postmortems and for this site. The tooling that produces the findings is private.
