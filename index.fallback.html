Two real reports

A real report · Compound v2 · Ethereum

2 days.

Changes made through the admin wait at least 2 days. The admin role is a Timelock: a contract that makes every change wait before it applies.

queued172800 sapplies
01 day2 days

Guardian roles · some actions · no delay · not in this report

Not part of this report. Separate guardian roles, held by another address (0xbbf3f1421d886e9b2c5d716b5192ac998af2012c), can pause some functions and set borrow caps without that delay. The same address is also the Governor’s proposal guardian: until 28 February 2030 00:00 UTC it can cancel a proposal at any stage before the proposal is executed, with no delay. A pending proposal would move that date to 1 November 2026. These guardian powers were read at block 26279840.

The Timelock 0x6d903f6003cca6255d85cca4d3b5e5146dc33925, delay 2 days (172800 seconds)
Who controls the Timelock
The Compound Governor contract 0x309a862bbc1a00e45506cb8a802d1ff10004c8c0. COMP holders vote in it.

The admin can, among other things, set the price oracle, the collateral factors, the close factor and the liquidation incentive, add new markets and set borrow caps.

I read this on the blockchain on 26 October 2026. I used two independent public nodes, and they gave the same answers. Block 26276583: the admin, the Timelock and the Governor. Block 26279840: the guardian powers. This is not a judgement: signers and delays change. The code I read: Comptroller.sol and Timelock.sol, from the public repository. I did not compare it with the code deployed on the blockchain. So this says what the repository says. It does not prove which code is executed. To check, compare the verified source on Etherscan with the repository.

A real report · Morpho Blue · Ethereum

6 of 10.

Six of the ten signers of one Safe can change the settings of Morpho Blue that the owner controls. A Safe is a multisig wallet: several keys must sign together. There is no delay before the change applies.

6 of 10 signed applies, no delay

Any six. Which six is not shown.

Who can change it
One Safe: 0xcba28b38103307ec8da98377fff9816c164f9afa
Signatures needed
6 of 10 signers (9 plain accounts, 1 contract)
Delay
None: the Safe is the owner itself, with no timelock in between

The owner can change the owner. For future markets, the owner can enable new interest rate contracts and new LLTVs (an LLTV is the loan-to-collateral ratio at which a position can be liquidated). The owner can set a fee (25% at most) and the address that receives it. The owner cannot move funds. The owner cannot change the settings of an existing market.

Same method as for Compound v2: two independent public nodes gave the same answers, at block 26276583. The code I read: Morpho.sol, from the public repository. I did not compare it with the code deployed on the blockchain. So this says what the repository says. It does not prove which code is executed. To check, compare the verified source on Etherscan with the repository. If you maintain one of these contracts and see a mistake, write to me.

Try it on any contract

Who controls it?

Type the address of a contract on Ethereum. I read its owner, its admin, its multisig and its delay. I show the command for each line.

Or try:

“Read this contract now” sends data from your browser to a public Ethereum node (ethereum-rpc.publicnode.com). It sends the address you typed. It also sends the addresses that it finds behind that address, one after the other. The node also sees your IP address and the name of this site. This happens only when you click the button or press Enter. Nothing is sent while you type. I never see this data. “Show me the commands” sends nothing.

The result appears here: first the owner, then who controls the owner.

RPC=https://ethereum-rpc.publicnode.com
M=0xYourContractAddress
q() { curl -s $RPC -H 'content-type: application/json' -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"eth_call\",\"params\":[{\"to\":\"$1\",\"data\":\"$2\"},\"latest\"]}"; }
r() { curl -s $RPC -H 'content-type: application/json' -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"$1\",\"params\":[$2]}"; }
r eth_getCode "\"$M\",\"latest\""   # is there contract code?
q $M 0x8da5cb5b   # owner()
q $M 0xf851a440   # admin()
r eth_getStorageAt "\"$M\",\"0xb53127684a568b3173ae13b9f8a6016e243e63b6e8ee1178d6a717850b5d6103\",\"latest\""   # proxy admin slot (EIP-1967)
# then, for the address returned by owner() or admin():
O=0xAddressReturnedAbove
q $O 0xe75235b8   # getThreshold(), if it is a Safe
q $O 0xa0e67e2b   # getOwners()
q $O 0xf27a0c92   # getMinDelay(), if it is a timelock
q $O 0x6a42b8f8   # delay(), the timelock of some protocols
q $O 0xf851a440   # admin(), who administers a timelock

Run it again

Three commands.

Ask a public node who owns the contract, then ask the owner how many signatures it needs.

Example: the three commands, sent to Morpho Blue. The first answer is shown exactly as the node returns it. The other two answers are decoded. These are read-only questions sent to a node: nothing is signed and nothing is paid.
