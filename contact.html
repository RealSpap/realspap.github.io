What happens after your message

  1. 1
    You write

    The address of the contract, its blockchain, and one line on what the contract is used for. The “Open the prepared e-mail” button opens an e-mail with these lines ready to fill in; nothing is sent until you send it.

  2. 2
    I read

    From public nodes: who can change it, how many signatures it needs, what delay applies. I note what I could not read.

  3. 3
    You get a report

    By e-mail. Each line comes with the command that produced it, so you can run it again.

There are no third-party scripts. You can run every command again yourself. The address reader on the home page sends nothing unless you click “Read this contract now”: that click asks a public Ethereum node about the address you typed and about the contracts behind it. The Oracle (testnet) dashboard contacts other hosts when you open it: GitHub, public blockchain nodes and an icon service. Findings, data, published code and blockchain sources are public.
