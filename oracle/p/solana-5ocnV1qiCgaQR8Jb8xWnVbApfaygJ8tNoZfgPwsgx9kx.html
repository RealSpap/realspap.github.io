Why this score

Two paths bind the score: a 6-of-11 Squads v3 program upgrade and a 4-of-8 Squads v4 pool admin with no delay, which decides how every LST is valued.

pool admin binds the score

The pool admin can call SetSolValueCalculator and SetPricingProgram, which decide how each LST is valued; the seven calculator and pricing programs share the same upgrade authority. The rebalance authority is a single on-curve key but bounded: EndRebalance must follow in the same transaction and rejects any drop in pool SOL value, so it is disclosed and not scored.
