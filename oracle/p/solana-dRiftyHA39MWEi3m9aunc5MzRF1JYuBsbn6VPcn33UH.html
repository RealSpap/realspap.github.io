retroactive backtest of the 2026-04-01 exploit

The repo verified on chain the two transactions on 2026-04-01 that used the old multisig to reassign Drift's admin key. The roughly 31 withdrawals were not re-derived. That multisig also had a non-default config_authority, not traced further. Retroactive score of that setup: 32. Now the upgrade multisig is 4-of-7 (6 can vote), 1-hour delay, autonomous. The DAO realm authority is self-governed: token vote with a 2% yes threshold, 1-day hold-up, 4-day voting, plus a 5-seat council that can only veto. The oracle sub-score rests on one Switchboard-fed market (AI16Z), not every market.

3 of 6 applicable requirements met

  • ✓ Admin power is not a bare key
  • ✓ At least a 3-of-5 multisig
  • ✗ A confirmed delay before changes apply, no bypass
  • ✗ Bypass paths of the delay checked and ruled out
  • ✗ Price feed not under one hand
  • ✓ No key shared with another tracked protocol

Exit window: a delay with a bypass, or one not ruled out, the time a user has to leave after a harmful change is queued.

Reproduce the independent read yourself (3 public RPC calls, no key)

This reads the program that holds the account, then its ProgramData, then the Squads v4 committee that is the upgrade authority. Each call is a plain JSON-RPC request to a public Solana RPC; the last step, when there is one, is a short Python 3 program with no library.

# 1. The program: its ProgramData account is the one that holds the upgrade authority (value.data.parsed.info.programData)
curl -s -X POST https://api.mainnet-beta.solana.com -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"getAccountInfo","params":["dRiftyHA39MWEi3m9aunc5MzRF1JYuBsbn6VPcn33UH",{"encoding":"jsonParsed"}]}'

# 2. The ProgramData: the upgrade authority (value.data.parsed.info.authority)
curl -s -X POST https://api.mainnet-beta.solana.com -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"getAccountInfo","params":["7dLgmtcTavcguNoynVimF9ZNVb13FvhXVRfj2HyrDGaP",{"encoding":"jsonParsed"}]}'

# 3. The Squads v4 committee: threshold, time lock and number of members
curl -s -X POST https://api.mainnet-beta.solana.com -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"getAccountInfo","params":["7qipzLR9j1JcvdxE1XJEFgvoyFmgBpgw5hMdHBMPcJtM",{"encoding":"base64"}]}' | python3 -c 'import base64,json,struct,sys;d=base64.b64decode(json.load(sys.stdin)["result"]["value"]["data"][0]);t,l=struct.unpack_from("<HI",d,72);o=94;o+=1+32*d[o];o+=1;print("threshold",t,"time_lock_s",l,"members",struct.unpack_from("<I",d,o)[0])'

# 4. Is the upgrade authority the vault 0 of that committee? Derive the vault address offline (Squads v4 program SQDS4ep65T869zMMBKyuUq6aD6EgTu8psMjkvj52pCf)
python3 - <<'PY'
import hashlib as H
A = "123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz"; P = 2**255 - 19; D = -121665 * pow(121666, P - 2, P) % P
dec = lambda s: int(sum(A.index(c) * 58**i for i, c in enumerate(reversed(s)))).to_bytes(32, "big")
def enc(b):
    n = int.from_bytes(b, "big"); s = ""
    while n: n, r = divmod(n, 58); s = A[r] + s
    return "1" * (len(b) - len(b.lstrip(b"\0"))) + s
def on_curve(b):
    y = int.from_bytes(b, "little") & ((1 << 255) - 1)
    if y >= P: return False
    x2 = (y * y - 1) * pow(D * y * y + 1, P - 2, P) % P
    return x2 == 0 or pow(x2, (P - 1) // 2, P) == 1
for bump in range(255, -1, -1):
    h = H.sha256(b"multisig" + dec("7qipzLR9j1JcvdxE1XJEFgvoyFmgBpgw5hMdHBMPcJtM") + b"vault" + bytes([0]) + bytes([bump]) + dec("SQDS4ep65T869zMMBKyuUq6aD6EgTu8psMjkvj52pCf") + b"ProgramDerivedAddress").digest()
    if not on_curve(h): print("vault 0 of the multisig =", enc(h)); break
