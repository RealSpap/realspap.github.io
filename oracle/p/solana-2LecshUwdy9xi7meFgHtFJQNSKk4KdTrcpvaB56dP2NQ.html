Why this score

Upgrades look strong (24-hour delay, 5-of-13), but a separate reward authority on the same config is a 1-of-8 multisig with no delay, which scores like a single key. Counting it as full-power is a disclosed judgment call.

judgment call: reward authority counted as full-power

WhirlpoolsConfig holds three authorities. fee_authority is the same Squads v4 vault as the program upgrade (5-of-13, 9 can vote, 24h delay). collect_protocol_fees_authority is a bare wallet but only withdraws already accrued fees, so it is bounded and not scored. reward_emissions_super_authority is a different Squads v4 vault, 1-of-8, no delay. It can reassign the reward authority of any pool without that pool's consent, and that authority can set the pool's emission rate. A reviewer could argue it is bounded, and the scorer lays out the reasoning. DefiLlama listed over $200M TVL on 2026-09-17.
