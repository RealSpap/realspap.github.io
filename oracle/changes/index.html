What changed today

The Watch reads who can change what every six hours. This page lists every change it recorded on one UTC day: an administrator read differently, an implementation changed, a Safe signer added or removed. It reads five public files of the Watch in your browser and checks them before it shows anything.

    Redo it

    Three commands that redo the checks in a terminal. Each line of the list above carries its own command for that change.

    # 1. the journal: each line carries the SHA-256 of the line before it
curl -s https://raw.githubusercontent.com/RealSpap/authority-risk-oracle-showcase/watch-data/events.jsonl | python3 -c "import sys,json,hashlib as h;L=sys.stdin.buffer.read().splitlines();print(sum(json.loads(L[i])['prev']==h.sha256(L[i-1]).hexdigest() for i in range(1,len(L))),'of',len(L)-1,'links valid')"
# 2. the signed manifest: the public key, and the SHA-256 it records for the four files this page reads
curl -s https://raw.githubusercontent.com/RealSpap/authority-risk-oracle-showcase/watch-data/signature.json | python3 -c "import sys,json;s=json.load(sys.stdin);print(s['public_key'],s['signed']);print({k:v for k,v in s['manifest']['files'].items() if k in ('events.jsonl','latest.json','authority-changes.json','safe_changes.json')})"
# 3. the same SHA-256, computed by you
for f in events.jsonl latest.json authority-changes.json safe_changes.json; do curl -s https://raw.githubusercontent.com/RealSpap/authority-risk-oracle-showcase/watch-data/$f | shasum -a 256; done

    What this page does not say

    It does not say why anything changed, who did it, or whether it is good or bad. "Administrator read differently" means that the reading of the administrator differs from the one of the previous run; "Implementation changed" on Solana means that the program was redeployed since the previous run. Those are the words of the Watch. For a Safe the page lists only the signers added and removed on the networks the Watch reads. It shows no score, no rank and no protocol name: a target is an address, as the Watch writes it. A network with no reading, or with a reading for part of the day only, is named above: it is not a zero. A file that does not verify is never shown as a zero either.

    To see a past UTC day, add its date after the address in the form #YYYY-MM-DD. The files hold a limited history: a day that they do not cover in full says so.

    The page asks raw.githubusercontent.com for the five files, so GitHub sees that request as it sees any file request. It keeps nothing in your browser and sends nothing to me.

    The five files are on the watch-data branch. Back to the oracle. These are readings of public data, not an opinion on security. Not an audit, not investment advice.
