So the base is Algebra Integral v1.0, but the deployment is not stock: it carries 10 extra function selectors -- initialize(address), createPlugin, createVaultForPool, getVaultForPool, deploy, isPublicPoolCreationMode, setIsPublicPoolCreationMode, POOLS_CREATOR_ROLE, plus 2 that no signature database resolves (0x5a05180f, 0x7965db0b -- the same two also appear in GIGA V3's controller above) -- plus solc's own Panic(uint256).
