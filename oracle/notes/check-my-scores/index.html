Check my scores in one command

I publish risk scores for 202 targets, and nobody should have to take my word for them. One command compares each published score with what eight oracles on test networks hold.

8 OKoracles replayed against the chain

read at 08:42Z on 15 November 2026. This page needs no script and no tool to read.

The command clones the public repository and runs scripts/prove.py. It reads the eight oracles on Robinhood Chain testnet (chain ID 46630), Ethereum Sepolia (chain ID 11155111), Arbitrum Sepolia (chain ID 421614), Base Sepolia (chain ID 84532), Tempo Moderato (chain ID 42431), Plasma testnet (chain ID 9746), Monad testnet (chain ID 10143) and HyperEVM testnet (chain ID 998), and the oracle on Solana devnet, and compares what they hold with the files the repository publishes.

Limit

It shows that the published files and the chain agree, not that a score is right. A node that does not answer gives UNREAD, never a pass, so run it again. The oracles are on test networks; the contracts they describe are on mainnets.
