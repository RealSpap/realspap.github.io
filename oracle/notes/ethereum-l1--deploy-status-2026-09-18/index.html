Before doing anything else, this run checked whether either of the two things that justified run 2 (a changed scorer, or a funded deployer) had happened again since:

chains/ethereum-l1/scorers.py, script/Deploy.s.sol and update_scores_ethereum_l1.py are byte-identical to run 2.
