Source: watch/API.md in the repository, rendered here without changes. Source file

Everything the dashboard shows from the watch is a file rewritten by the Watch GitHub Action every 6 hours (17 */6 * * * UTC), committed to the watch-data branch of this repository (the root of the branch is the folder that is called watch/ in the scripts and in this document) and served raw from https://raw.githubusercontent.com/RealSpap/authority-risk-oracle-showcase/watch-data/<file>. main holds the code and the documents written by hand (this one, the README and the schemas, copied into the branch at every run), so its history is the history of the work. Before the move the same files were committed to main under watch/; those commits stay, and the old links answer with a short notice that points here. status.json carries data_location, the base URL under which every file is served, so a page or a monitor does not need a constant of its own (the notice left on main carries it too). No key, no rate limit beyond GitHub's. The on-chain source of truth stays the oracle contracts (getScore(address)): these files are a convenience read of them.

What the checks do not prove (written down on 2026-10-11 after a security review). (1) The signature is checked with the public key written inside signature.json: a forged manifest signed with a random key still says "valid". It proves the files match what that key signed, not who holds the key; the maintainer's public key is 11baca3ef6a69de4901c185f6cbbd3f93318fbb74f9961a8d39aead841adf409, pinned in the dashboard (ARO_PUBKEY) and written here: compare it with the public_key of signature.json, and treat a signature made by any other key as invalid. Before 2026-10-11 21:18 UTC the runs were unsigned (signed: false), and a run that cannot read the secret says so. (2) verify_chain.py checks that every line commits to the previous one; it cannot see that the end of the log was cut off. The head of the chain is pinned in the signed manifest (events_chain_head), so compare that value, not only "chain intact". (3) An alarm is a line of events.jsonl and an issue in the maintainer's private repository, and only when the ISSUES_TOKEN secret is set: without it the run prints "alarm raised but no ISSUES_TOKEN" and nobody is told. An oracle that stops answering raises one alarm, then stays silent while it stays unreadable: read status.json for the current state.

Auditing all of this from outside, in one command and with the standard library only: python3 scripts/audit_public.py fetches the published files, checks the event-log chain, the signed manifest and its signature (pynacl), the schemas, the methodology registry, and re-reads a random sample of scores from the oracle contracts over public RPCs; --watch watch audits a local checkout, --sample N sets the sample, --ref <commit> audits a past run as it was committed (its signed manifest, chain and schemas), since every run commits its manifest.
